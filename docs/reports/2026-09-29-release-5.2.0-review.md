## Resumen ejecutivo

El candidato combina el producto ya revisado en develop con el historial de
main. No modifica fuentes Rust, tests, scripts ni workflows frente a develop:
se verificó identidad con `git diff`. Los conflictos de CHANGELOG/TASKS se
resolvieron conservando ambos historiales. El changelog de 5.1.5 y versiones
anteriores permanece idéntico byte a byte. Versiones de manifiesto, lock e
instrucciones de instalación coinciden en 5.2.0.

identificación opcional del writer, conservación incremental, preparación de
participantes de firmas, correcciones tagged split/outline/metadata y espaciado

PAdES queda fuera de la librería y disponible como extensión independiente.

#642 / PR #658 se excluye: no hay feature recipient-encryption ni nuevo camino
RSA privado en el código o paquete. Sus 17 checks verdes no eliminan el bloqueo
de aceptación de seguridad. El handler público legacy continúa rechazando
operaciones simuladas, como requiere #640.
