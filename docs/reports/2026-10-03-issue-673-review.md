# #673 — avance vertical del pen

## Resumen ejecutivo

Issue #673 creada y confirmada OPEN antes de corregir, vinculada a #666.
Candidato local sobre #671/#672; sin commit/PR/merge/release. Se corrige el avance
del pen de fuentes Type0 verticales; no se afirma un renderer ni layout vertical
completo o aplicación visual de los offsets v1x/v1y.

## Contratos y evidencia

Diez RED anteriores pasan (nueve de text_vertical_contract_test y uno CID-CFF).
Seis controles adicionales pasan: Tw no se aplica a códigos de dos bytes, ambos
signos TJ con Tz50/200, rotación CTM, cambio de tamaño, selección W2 de cada CID
y ToUnicode multiescalar que conserva dos avances para dos códigos fuente.
Los contratos verticales suman15; CID-CFF6. Regresiones TJ horizontal, APIs de
salida y tracking #663 pasan en expanded-final.log.

Cinco controles internos de W2/DW2: defaults, referencias indirectas, rango
0..65535 guardado como un intervalo (sin expandirlo), límite de CID e incompletos,
rangos invertidos/inválidos y números indirectos. Default vertical -1000;
se usa w1y por CID con fallback DW2. Tc/Tw se aplican por código fuente; TJ mueve
y sin Tz. Las métricas de avance vertical no se reutilizan como una anchura
negativa del fragmento. La certificación de tracking permanece horizontal.

Biblioteca **6792 PASS/0 FAIL/3 omitidas**; Clippy focalizado aprobado. Corpus
diferencial **72/72**,278/211815 fusiones,1695 comparados; orden1058,594837 palabras,
misplaced110427 plano/94887 reading-order: igual que el candidato #671/#672.
Sin cambios de umbrales. Evidencia en 2026-10-03-issue-673-evidence/.

## Hallazgos

1. Las métricas verticales estaban ausentes y el pen avanzaba por x. Se añaden
   W2/DW2 compactos y un avance por código fuente en Tj/TJ y operadores quote;
   los diez fallos iniciales discriminan el cambio y pasan tras corregir.
2. Un fallback contado por Unicode multiplicaría avances cuando un glifo tiene
   ToUnicode multiescalar. Se cuentan códigos/CIDs; el control fi+emoji seguido
   de otro glifo sitúa el segundo run en y680, no y670.
3. La recuperación de un Encoding vertical nombrado cuyo code→CID no esté
   resuelto sigue siendo aproximada por unidades de dos bytes. No certifica
   variantes UTF16 suplementarias ni CMaps variables no soportados. Completar
   esas rutas necesita las baterías de colecciones correspondientes; no se
   presenta esta corrección del pen como cobertura de todas las CMaps CJK.
