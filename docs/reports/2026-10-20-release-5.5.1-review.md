1. **Concurrent first-launch configuration creation**:
   `.github/workflows/interoperability.yml:65` — launching two validators before
   initialization can fail before PDF processing. Corrected by a successful
   single `verapdf --version` invocation before parallel tests. The scheduled
   real-tool RED/GREEN is retained in `race-{red,green}.log`.
2. **Aggregate failure hides tool diagnostics**:
   `oxidize-pdf-core/tests/issue_729_external_validators_test.rs:35` — None alone
   cannot distinguish execution/report failures. Added the complete result to
   assertions without changing expected values or skipping failures.
3. **Semantic example prevents all-target lint validation**:
   `oxidize-pdf-core/examples/pdf_to_llm_formats.rs:153` and `:155` — redundant
   literal format arguments trigger print_literal. Replaced them with the same
   output literals; no export or feature behavior changes.
