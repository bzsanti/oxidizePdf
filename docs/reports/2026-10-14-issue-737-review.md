Base develop b657fa09d49bc1e6559b46d1aa47984640cba19c; Rust 2021/MSRV 1.88,
features predeterminadas. Se revisa la frontera pública SemanticRedactor::redact,

La revisión parte de los criterios de #737 OPEN, no de las expectativas de la
suite existente. Los controles usan un PDF de dos páginas construido sin el
writer del producto y validado por qpdf/Poppler. La corrección no convierte la
máscara visual en eliminación de información y no completa la auditoría #719.

Eliminar el guard reproduce los tres fallos RED. Validar todas las entidades sin
filtrar rompería el control de tipos no seleccionados. Cambiar > por >= rompería
el control de última página. El ensayo ejecutado es RED/GREEN del guard completo;
las otras dos mutaciones se describen, no se afirman ejecutadas.

Trazado manual: BoundingBox.page documenta 1-indexado; PdfDocument::page_count
obtiene el árbol; la lista filtrada decide tanto validación como agrupación. El
bucle de salida consume exclusivamente páginas existentes; cada seleccionado
admitido llega a su página. La comparación u32 no suma ni resta valores de entrada.
El primer error sigue el orden de entrada y no el orden arbitrario de HashMap.
La API es pura respecto al llamador: no recibe un archivo de salida que pudiera
quedar parcialmente escrito. Fallos de parser/reconstrucción se siguen propagando.
El camino sin selección mantiene el retorno de bytes original, sin parseo nuevo.
