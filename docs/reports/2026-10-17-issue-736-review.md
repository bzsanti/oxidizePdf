# Review #736 — preserve PNG sample depth

Issue: #736 — fix(images): preserve PNG sample depth or convert samples before declaring 8 bits — https://github.com/bzsanti/oxidizePdf/issues/736

The importer retains all 16 bits of grayscale/RGB samples and separates grayscale/RGB alpha by whole samples. Both image and SMask dictionaries declare the retained depth. Existing eight-bit behavior remains covered. No public signature or dependency changes.

## Contract evidence

Independent image::PngEncoder fixtures are decoded independently before import. Literal expected sample values exercise both bytes, zero/full alpha and intermediate alpha. Public Image accessors, Document serialization and reopened PDF streams agree; qpdf independently extracts main and mask streams and checks BitsPerComponent 16. The external oracle is explicitly selected in CI, without optional-success fallback.

Original RED: four failures and one eight-bit control pass. Final: six new contracts, two PNG rendering regressions and nine transparency regressions pass, including the qpdf oracle. Six decoder and 53 image unit tests pass. Strict all-target Clippy passes. Logs are adjacent.

## Findings and resolution

Review found unchecked geometry multiplication on hostile 16-bit dimensions. A valid-CRC fixture with maximum 31-bit dimensions reproduced an overflow panic; checked row/image arithmetic now returns InvalidImage. The negative contract passes without a panic. This is the only additional blocking finding; resolved before acceptance.

Manual review traced decompression, row unfiltering, sample separation, Image construction, main and mask serialization. Required byte count is checked before row allocation/indexing; existing 256 MiB decompression cap is retained. Alpha splitting uses validated decoded row data and preserves byte order. No new unsafe code or external I/O is introduced in production. This is not a whole-parser resource audit.

## Calidad de Tests (Kripteia)

Required analyses ran on both product files and the integration contracts. Decoder 95/100 (six tests), Image 96/100 (53), contracts 93/100 (six). Existing enum-only assertions do not prove this correction; the new public sample and serialized-stream contracts do. The qpdf test intentionally requires an installed executable; it fails if unavailable when explicitly run. Expected values are literal samples, not outputs from the production conversion.

## Análisis de Seguridad (Kripteia Security)

All three scans report no security issues. Manual geometry review found and resolved the overflow described above; scanner results alone were not treated as proof. PNG palette/tRNS, interlacing and packed low-bit support are outside this correction. The separately recorded 16-bit image-extraction stride finding is not fixed by this import change.
