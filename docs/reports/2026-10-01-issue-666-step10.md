Trece tests nuevos; inventario total 102. Ocho prueban secuencias Unicode de
latino occidental/ampliado, griego/cirílico, árabe/hebreo, devanagari/tailandés,
suplementarios, variantes, ZWJ y formas canónicas distintas. Los operandos
UTF-16BE y las expectativas literales se escriben separadamente: no se genera
el oráculo convirtiendo el texto esperado con código de producto. Se prueban
modos strict/lenient. Estos contratos no afirman shaping, bidi ni tipografía;
la fuente representa un glifo con secuencia Unicode explícita.

Cinco contratos adicionales distinguen las cadenas documentales PDF 2.0 de los
códigos de fuente. PDF 2.0 permite UTF-8 con BOM EF BB BF (ISO 32000-2 7.9.2.2;
https://pdfa.org/understanding-utf-8-in-pdf-2-0/). Se prueban seis secuencias en
metadata y ActualText, PDFDocEncoding sin BOM, interpretación PDF 1.7 y control
de Tj cuyos bytes de BOM pertenecen a la codificación de fuente.
