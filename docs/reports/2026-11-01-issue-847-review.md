# Revisión de #847: presupuestos del chunker semántico

## Resumen ejecutivo

Issue: #847 — fix(pipeline): semantic chunker violates selected token budgets at joins and overlap — https://github.com/bzsanti/oxidizePdf/issues/847

Incremento de #710; desbloquea parte de bzsanti/oxidize-pdf-dotnet#104. Base de implementación: develop `fd07497d3c18e8d68e68162839217f8fd6bc7323`. Reproducción independiente contra registry `oxidize-pdf =5.5.5`: Paragraph("a"), Paragraph("b"), cl100k_base, max_tokens=2, overlap=0 devuelve `a\nb`, count=3, oversized=false. HybridChunker devuelve dos fragmentos válidos; #435 corregía solo ese camino.

La corrección mide uniones con el contador seleccionado, limita overlap al presupuesto de solapamiento y al del siguiente fragmento, y deriva el indicador de exceso del texto final. Conserva estructuras/frases indivisibles sobredimensionadas. El solapamiento es de mejor esfuerzo: puede omitirse si no cabe; no se supone monotonía de BPE. Se conserva la ruta aditiva del contador por palabras. Sin cambios de dependencia, API pública, versión o publicación.

## Arquitectura: SOLID y Clean Architecture

Ruta inspeccionada: elementos → SemanticChunker → TokenCounter → SemanticChunk, reexportada por `pipeline/mod.rs:31`.

- SRP: política de fragmentación permanece en `semantic_chunking.rs`, sin mezcla de transporte/FFI o administración de builds.
- OCP y DIP: `with_token_counter` admite contadores implementando el contrato existente; código de política no importa el proveedor tiktoken.
- LSP: WordProxy, contador no aditivo Characters y cl100k_base ejercitan la misma postcondición de presupuesto/flag. `is_additive_over_whitespace_join` autoriza únicamente la optimización declarada. No se exige monotonía para la búsqueda de overlap.
- ISP: no se añaden métodos ni capacidades forzadas al puerto. No aplica una nueva separación de interfaces.
- Variación comprobada: sustituir WordProxy por BPE requiere inyectar el contador, sin modificar DTO, red ni almacenamiento. Resultados respaldados por pruebas locales; no certifican todo el repositorio.
