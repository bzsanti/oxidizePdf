# QR #732 — packed grayscale extraction

## Resumen ejecutivo

Issue: #732 — fix(images): decode packed grayscale samples during image extraction — https://github.com/bzsanti/oxidizePdf/issues/732

Base develop 075b5f7b. Scope: 1/2/4-bit grayscale Image XObjects through the public in-memory extractor, checked row/pixel lengths and 8-bit PNG output with optional soft mask. Existing unpacking is reused only after validating all packed rows. ImageMask/Decode inversion, color management and 16-bit extraction are not certified. No dependency/public API additions.

## Análisis de Seguridad (Kripteia Security)

All scans report `No security issues found.` Manual review verifies packed byte and output pixel counts with checked arithmetic before allocation or indexing; source data length is validated before reuse of the existing unpacker. Bit shifts are restricted to 1/2/4; u16 scaling cannot overflow. Existing extraction limits are honored, but default limits remain caller-configurable/unbounded and this is not a general memory-cap guarantee. No unsafe/FFI/file/network functionality added.
