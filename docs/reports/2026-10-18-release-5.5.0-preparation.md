# Release 5.5.0 preparation review

Issue: #787 — https://github.com/bzsanti/oxidizePdf/issues/787

Baseline release: v5.4.2. Product source: develop
c440d5bf9181b2b93f467870899e86479022dd9a.

## Scope and decision

Minor 5.5.0 reflects additive APIs since 5.4.2. This preparation changes only
version metadata, lockfile package versions, README and release documentation.
No product source, tests, dependency selections or CI workflows are changed.
Manual review checked both lockfiles, package inheritance, release trigger,
changelog against the commit history and bridge migration caveats against the
implemented contracts. No preparation blocker found.

Existing per-issue reviews and test/security evidence remain applicable to the
unchanged product source, including #758, #770, #771, #774 and #776. This is a
release-metadata review, not a new exhaustive audit of the entire library.

## Validation

- `cargo semver-checks check-release -p oxidize-pdf --baseline-version 5.4.2`:
  PASS against the registry baseline, deriving the release type from the version.
- `cargo package --locked --offline --allow-dirty -p oxidize-pdf`: PASS, packaged
  and compiled 5.5.0. Allow-dirty covers the reviewed preparation diff.
- `cargo fmt --all -- --check` and `git diff --check`: PASS.
- WASM harness `cargo metadata --locked --offline --no-deps`: PASS.
- Workspace version and both lockfiles checked as 5.5.0; dependency resolutions
  unchanged. Source/test/workflow diff against the product source is empty.

Logs: [SemVer](2026-10-18-release-5.5.0-evidence/semver.log),
[package](2026-10-18-release-5.5.0-evidence/package.log).

Packaging reports existing yanked dependencies chacha20 0.10.0 and spin 0.9.8.
They did not prevent locked packaging. No dependency upgrade or security claim
is made by this preparation. Remote checks on the preparation PR remain required
before integration. Tag, main merge and registry publication are not performed.
