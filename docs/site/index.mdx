Use the `oxidize-pdf` crate to create PDF documents, read existing PDFs and extract text. These guides target **5.5.5**.

Start with [installation and a complete example](/quickstart). Check [version and capability limits](/scope) before using optional features.

The [versioned Rust API reference](https://docs.rs/oxidize-pdf/5.5.5/oxidize_pdf/) documents types and methods beyond this introductory site. [Runnable examples](https://github.com/bzsanti/oxidizePdf/tree/v5.5.5/oxidize-pdf-core/examples) cover additional operations.

Python and .NET have their own package versions and APIs:
- [Python repository](https://github.com/bzsanti/oxidize-python)
- [.NET repository](https://github.com/bzsanti/oxidize-pdf-dotnet)

For documentation inside a coding assistant, see [Context7](/context7).
