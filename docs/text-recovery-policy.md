# Política de extracción y recuperación de texto

Esta política distingue Unicode, códigos fuente, métricas y programa de glifos. Obtener texto no certifica que un programa de fuente pueda renderizarse. `ParseOptions::strict()` tampoco convierte toda la recuperación histórica de texto en un validador integral de PDF.

Las reglas normativas de diccionarios, fuentes y estado de texto se basan en [ISO 32000-1:2008, §§7.3.9 y 9](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf). Las heurísticas de separación y las decisiones sobre datos dañados son políticas de esta biblioteca. La CI y la integración se registran aparte del cierre local de estos contratos.

| Caso | Extracción estricta | Extracción tolerante | Consumidor de fuente resuelta / evidencia |
|---|---|---|---|
| ToUnicode presente y utilizable | Tiene prioridad; una entrada ausente/inválida no habilita otro Unicode de base | Igual | Mantiene prioridad; Unicode desconocido puede ser None, mientras extracción emite U+FFFD. [Unicode](../oxidize-pdf-core/tests/text_unicode_policy_contract_test.rs) |
| ToUnicode no es stream, no se puede decodificar, contiene ciclo o excede el límite de referencias | Error | Mapa vacío autoritativo: reemplazos visibles, sin volver al encoding de base; conserva los límites conocidos de códigos | Rechaza el recurso inutilizable en ambos modos. Hasta16 referencias acíclicas; controles16/17 y ciclo. [Recuperación](../oxidize-pdf-core/tests/text_recovery_boundary_contract_test.rs) |
| ToUnicode null o referencia inexistente | Equivale a ausencia | Igual | No se confunde con stream inválido. [Métricas/null](../oxidize-pdf-core/tests/text_metrics_boundary_contract_test.rs) |
| CMap con código desconocido o cola incompleta | Reemplazo por código fallido; no reinterpretar sufijos ni unir strings TJ | Igual | Decodificación resuelta puede rechazar códigos truncados; no se promete el mismo manejo de errores. [Límites](../oxidize-pdf-core/tests/text_recovery_boundary_contract_test.rs), [CMap](../oxidize-pdf-core/tests/text_cmap_boundary_contract_test.rs) |
| Colección CID privada, incoherente o malformada | No autoriza tabla Unicode de otra colección; ToUnicode explícito conserva prioridad | Igual | Código/CID y Unicode son autoridades distintas. [Colección](../oxidize-pdf-core/tests/text_cid_collection_policy_contract_test.rs) |
| Descendiente Type0 dañado, sin métricas certificadas | No activa inferencia de tracking por datos desconocidos | Recuperación sólo horizontal, con un glifo por string, ToUnicode completo, espacio dedicado, baseline de em permitida y mayoría | Recuperar texto no certifica ancho cero ni glifos renderizables. [Tracking](../oxidize-pdf-core/tests/text_tracking_recovery_contract_test.rs) |
| Descendiente resuelto, fuente simple o escritura vertical | Conserva sus controles de métricas/espaciado | No activa la excepción de descendiente Type0 dañado | [Espaciado](../oxidize-pdf-core/tests/text_spacing_contract_test.rs), [Vertical](../oxidize-pdf-core/tests/text_vertical_contract_test.rs) |
| Widths/W/DW/MissingWidth mal tipados o no finitos; límites inválidos | Error | Descarta las métricas inválidas y mantiene metadata Unicode; W inválido no conserva rangos parciales, usa DW válido o1000 | Resolución rechaza métricas inválidas en ambos modos. [Métricas](../oxidize-pdf-core/tests/text_metrics_boundary_contract_test.rs) |
| Entrada opcional de métricas null, directa o referenciada | Equivale a omisión | Igual | Incluye FirstChar/LastChar/Widths/W/DW/MissingWidth y FontDescriptor; null **dentro** de un array de anchos sigue siendo inválido. [Métricas](../oxidize-pdf-core/tests/text_metrics_boundary_contract_test.rs) |
| Programa de fuente ausente | Metadata explícita puede bastar para extraer | Igual | El recurso puede carecer de programa incrustado; eso no prueba que existan contornos. [Programas](../oxidize-pdf-core/tests/text_font_program_contract_test.rs) |
| FontFile/FontFile2 declarado con un tipo no stream | Puede conservar ToUnicode y métricas independientes | Igual | Resolución rechaza el recurso; null equivale a omisión. [Recuperación](../oxidize-pdf-core/tests/text_recovery_boundary_contract_test.rs) |
| Bytes de programa malformados | No se deduce una garantía genérica sólo de haber extraído texto | Igual | La validación depende del consumidor del programa: Type3/CharProcs y CFF tienen controles estructurales propios. Tener bytes en EmbeddedFont no certifica su ejecución. [Type3](../oxidize-pdf-core/tests/text_type3_program_boundary_contract_test.rs), [CFF](../oxidize-pdf-core/tests/text_cff_program_contract_test.rs) |
| CIDToGIDMap inválido | Puede conservar ToUnicode explícito | Igual | Resolución rechaza mapa inválido; ausente/null conserva la compatibilidad Identity. [CIDType2](../oxidize-pdf-core/tests/text_cid_truetype_program_contract_test.rs), [null](../oxidize-pdf-core/tests/text_metrics_boundary_contract_test.rs) |
| Fuente privada sin Widths ni MissingWidth | Conserva la estimación histórica500 para recuperar layout | Igual | Resolución expone0 sin métrica declarada. Ninguno constituye un oráculo de la fuente. Con MissingWidth explícito ambos lo respetan. [Métricas](../oxidize-pdf-core/tests/text_metrics_boundary_contract_test.rs) |
| Estado o geometría no representable, incluido overflow al reconstruir párrafo | Error explícito | Igual | Una matriz degenerada finita no es por sí sola un error; no se publica geometría infinita. [Transformaciones](../oxidize-pdf-core/tests/text_transform_contract_test.rs) |

Los valores cero declarados no se sustituyen por defaults. El Unicode puede contener varios escalares por glifo; eso no multiplica métricas ni Tc. Tw se aplica al código fuente de un byte32, no a cualquier espacio Unicode. Los ajustes TJ mueven el pen según el estado vigente; la separación textual inferida se evalúa aparte.

Los informes de #666 y coverage.json enlazan la validación concreta de cada fila. Una batería aprobada o un recurso construido no equivalen a conformidad integral, contornos validados ni CI completada.
